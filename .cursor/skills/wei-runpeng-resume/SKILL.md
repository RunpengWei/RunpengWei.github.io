# 韦润芃简历生成 Skill

## 用户怎么用

用户说明：**申请什么岗位 + 有什么要求**（篇幅、强调点、要不要某段经历），Agent 据此：

1. 读 [experiences.md](experiences.md) 选材
2. 按岗位挑亮点写进 `build_resume.py` 的 `B` 字典
3. 运行脚本输出一页 docx
4. 文件名体现岗位，如 `CV_WEI Runpeng_家辉教育语文教师.docx`

## 按需生成流程

```
用户诉求（岗位 + 要求）
    ↓
查 experiences.md「经历×岗位速查表」+ 各条亮点
    ↓
确定：保留哪些经历 / 删哪些 / 自我评价话术 / 是否强调 AI 或弱化
    ↓
更新 build_resume.py → python3 build_resume.py
    ↓
检查 CPL=48 行数 ≈ 50–53（一页）+ 页眉联系方式 + 超链接 + 一寸照
    ↓
交付 docx，简述选材逻辑
```

## 版式规范（所有岗位通用）

### 页面

- A4 一页；上边距 1.0 cm、下边距 0.9 cm、左右 1.6 cm；行距 **1.15**

### 字号与颜色

| 元素 | 规格 |
|------|------|
| 姓名 | 20pt 黑体 `#1A477A` |
| 联系标签 | 9pt 宋体 `#888888` |
| 联系内容 | 9pt 宋体 `#333333` |
| 网站链接 | 9pt 下划线 `#1A477A` |
| 分区标题 | 11pt 黑体 `#1A477A` + 底部分隔线 |
| 经历标题 | 10pt 加粗宋体 |
| 日期 | 9pt 宋体 `#666666` 右对齐 |
| 正文 | 9pt 宋体 两端对齐 |

### 页眉

左栏三行（姓名 / 电话+邮箱 / 网站超链接）+ 右栏一寸照（2.6×3.64 cm，右上顶对齐）。

### 篇幅秘诀

- **每行写满**：按 CPL=48 汉字估算；分点长度取 96 / 144 / 192 字（2/3/4 整行）
- 避免半行空白导致溢出 4–5 行
- 弱相关经历并入一条（如普林斯顿不写独立标题行；克孜尔并入学术研究）
- 用户 docx **下划线批注**必须遵守
